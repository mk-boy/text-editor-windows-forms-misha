# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## О репозитории

Учебная лабораторная работа №2 «Текстовый редактор» (C#, Windows Forms, .NET Framework 4.7.2). Условие — `Лабораторная работа №2.docx` в корне; состав меню и вид диалогов заданы **только рисунками** внутри docx (`word/media/image1..6.png`), текст их не описывает — при перечитывании условия смотри картинки.

Кратко по условию (аналог «Блокнота», можно ориентироваться на WordPad, дизайн любой):
- **Файл**: Создать (Ctrl+N), Новое окно (Ctrl+Shift+N), Открыть… (Ctrl+O), Сохранить (Ctrl+S), Сохранить как… (Ctrl+Shift+S), Выход.
- **Правка**: Отменить (Ctrl+Z), Вырезать/Копировать/Вставить (Ctrl+X/C/V), Удалить (Del), Найти… (Ctrl+F), Найти далее (F3), Найти ранее (Shift+F3), Заменить… (Ctrl+H), Перейти… (Ctrl+G). Корректная работа с буфером обмена.
- Поиск и замена — **в отдельной форме** (можно одна форма на оба режима): поле «Что:», направление Вверх/Вниз, кнопки «Найти далее» и «Отмена».
- **Формат**: Перенос по словам, Шрифт… (стандартный диалог выбора шрифта); также выравнивание текста.
- На рисунке главного окна есть меню «Вид» и «Справка», но их содержимое в условии не задано.

## Правила выполнения лабы

1. Делай **только то, что требует условие** — без лишних функций, настроек, рефакторинга «на будущее». Реализация должна быть небольшой и понятной для защиты; над дизайном сильно не заморачиваться (стандартные контролы, минимум оформления).
2. После того как решение готово, составь в корне файл `РЕШЕНИЕ.md` по инструкции ниже.

## Сборка и запуск

Тестов и линтера нет. Решение — `text-editor-windows-forms-misha.slnx` (формат .slnx требует Visual Studio 2022 17.13+ / MSBuild из VS 18). `dotnet build` не подходит — проект старого формата под .NET Framework, собирать через MSBuild из Visual Studio:

```powershell
& "C:\Program Files\Microsoft Visual Studio\18\Community\MSBuild\Current\Bin\MSBuild.exe" text-editor-windows-forms-misha.slnx -nologo -v:minimal
```

Результат: `text-editor-windows-forms-misha\bin\Debug\text-editor-windows-forms-misha.exe`.

## Архитектура и особенности проекта

- Проект создан шаблоном VS «Windows Forms App (.NET Framework)»; логика редактора — в `Form1.cs`, окно поиска/замены — `FindForm`, окно «Перейти» — `GoToForm`. `Program.cs`, `Properties\*`, `App.config` — шаблонные, их не трогать без необходимости.
- UI формы описывается в `Form1.Designer.cs` (метод `InitializeComponent`), обработчики — в `Form1.cs`. Контролы, добавляемые кодом вручную, должны быть в `Designer.cs` в том же стиле, что генерирует дизайнер, чтобы форма открывалась в дизайнере VS.
- `.csproj` — **старого (не SDK) формата**: каждый новый `.cs`-файл (например, форма поиска/замены) нужно явно добавить в `<ItemGroup>` как `<Compile Include=...>`; для формы — пара `X.cs` (`<SubType>Form</SubType>`) + `X.Designer.cs` (`<DependentUpon>X.cs</DependentUpon>`), иначе файл не попадёт в сборку.
- Пространство имён — `text_editor_windows_forms_misha`.
